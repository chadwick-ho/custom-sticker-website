Tool Reuse Handover — filling guide

Create a separate row for printing preparation, cutting tool, run setup or artwork delivery. IDs beginning EXAMPLE are invented planning references, not actual supplier tools. Procurement obtains first-order and unchanged-repeat charges against the same scope; unknown monetary values remain blank. Ask the supplier to confirm ownership, the retention period and its start event, inactivity/disposal notice and release conditions. Record file deliverables separately from hardware. The receiving printer confirms the actual tool and production conditions before reuse is planned; a release agreement is not compatibility evidence. Link the accepted quotation/acknowledgment. Review changed artwork, material, bottle or route before using a prior arrangement.
