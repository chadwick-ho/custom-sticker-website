Using this decision record

Worked entries are fictional planning examples. They are not customer orders, actual observations, specifications or approvals.

  1. both_expected: Follow actual program policy; no automatic authenticity verdict. Replace the demonstration reference with the actual controlled evidence. Record the named owner and observed result separately.
  2. visual_question: Preserve visual discrepancy and exact digital response. Replace the demonstration reference with the actual controlled evidence. Record the named owner and observed result separately.
  3. digital_question: Keep response/error and object reference; cause unknown. Replace the demonstration reference with the actual controlled evidence. Record the named owner and observed result separately.
  4. unavailable_check: Named fallback and decision owner must be supplied. Replace the demonstration reference with the actual controlled evidence. Record the named owner and observed result separately.

Do not fill an observed result from an expected result. Resolve the open decision with its responsible owner before releasing the affected scope.
