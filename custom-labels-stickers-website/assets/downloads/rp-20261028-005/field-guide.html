Using this decision record

Worked entries are fictional planning examples. They are not customer orders, actual observations, specifications or approvals.

  1. comparison_A: Proposed first orientation; no result. Replace the demonstration reference with the actual controlled evidence. Record the named owner and observed result separately.
  2. comparison_B: Proposed second orientation; same authorized data required. Replace the demonstration reference with the actual controlled evidence. Record the named owner and observed result separately.
  3. controlled_basis: Reader, bottle and symbol requirements to be confirmed. Replace the demonstration reference with the actual controlled evidence. Record the named owner and observed result separately.
  4. other_changes: List any size/material/setup difference before concluding. Replace the demonstration reference with the actual controlled evidence. Record the named owner and observed result separately.

Do not fill an observed result from an expected result. Resolve the open decision with its responsible owner before releasing the affected scope.
