Using the sku-gtin record

These are fictional planning examples, not an actual verification report, GTIN allocation or approval.

  1. Keep the example separate and enter the actual product and artwork references into the blank record.
  2. Record each actual trade item, its authorized GTIN source as text, the artwork revision and the reviewer. Stop mismatches; never replace missing approved values with DEMO data.
  3. The relevant owner supplies missing source documents and applicable acceptance criteria. A request is not evidence of approval.
  4. Document the decision and unresolved hold, then give the print supplier the correct approved file and project context.
