Using this decision record

Worked entries are fictional planning examples. They are not customer orders, actual observations, specifications or approvals.

  1. start_datum: DEMO front-face reference; actual bottle drawing needed. Replace the demonstration reference with the actual controlled evidence. Record the named owner and observed result separately.
  2. face_widths: Actual measured usable faces not supplied. Replace the demonstration reference with the actual controlled evidence. Record the named owner and observed result separately.
  3. corner_transitions: Actual start/end positions not supplied. Replace the demonstration reference with the actual controlled evidence. Record the named owner and observed result separately.
  4. content_mapping: Reviewed blocks to be assigned and checked after wrapping. Replace the demonstration reference with the actual controlled evidence. Record the named owner and observed result separately.

Do not fill an observed result from an expected result. Resolve the open decision with its responsible owner before releasing the affected scope.
