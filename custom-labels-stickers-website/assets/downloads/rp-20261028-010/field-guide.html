Using this decision record

Worked entries are fictional planning examples. They are not customer orders, actual observations, specifications or approvals.

  1. source_change: DEMO formula-source revision R2; no formula provided. Replace the demonstration reference with the actual controlled evidence. Record the named owner and observed result separately.
  2. ingredient_block: Potential dependency requires qualified review. Replace the demonstration reference with the actual controlled evidence. Record the named owner and observed result separately.
  3. other_blocks: Facts and allergen applicability unresolved. Replace the demonstration reference with the actual controlled evidence. Record the named owner and observed result separately.
  4. fit_check: Pending after exact approved text is supplied. Replace the demonstration reference with the actual controlled evidence. Record the named owner and observed result separately.

Do not fill an observed result from an expected result. Resolve the open decision with its responsible owner before releasing the affected scope.
