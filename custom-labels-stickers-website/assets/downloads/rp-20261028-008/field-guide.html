Using this decision record

Worked entries are fictional planning examples. They are not customer orders, actual observations, specifications or approvals.

  1. proposed_pack: DEMO PET pack; actual construction to be supplied. Replace the demonstration reference with the actual controlled evidence. Record the named owner and observed result separately.
  2. document_scope: Named supplier evidence not yet supplied. Replace the demonstration reference with the actual controlled evidence. Record the named owner and observed result separately.
  3. difference: Proposed printed coverage not reconciled with document. Replace the demonstration reference with the actual controlled evidence. Record the named owner and observed result separately.
  4. disposition: Qualified scope comparison required; no claim approved. Replace the demonstration reference with the actual controlled evidence. Record the named owner and observed result separately.

Do not fill an observed result from an expected result. Resolve the open decision with its responsible owner before releasing the affected scope.
