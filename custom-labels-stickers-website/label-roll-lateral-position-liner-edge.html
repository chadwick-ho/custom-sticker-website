Measure Label Position Across the Liner Before Approving a Roll

If a finished roll has the correct overall width but the bottle label lands too far to one side, measure where the cut label sits across the liner before changing the machine setup. Record the cut label's position on a flat sample and compare it with the position of the dispensed label on the bottle. A consistent offset on the supplied web and an offset introduced at application call for different reviews.

Put the liner edge and cut boundary on the same drawing

Ask the packer which edge the machine uses as its lateral reference. View the label face with the web feed direction marked. Specify the distance from the reference liner edge to the nearest cut edge. For a shaped label, mark the longitudinal point where that distance applies. Add the finished web width and the label shape to the same drawing. On the opposite edge, record the remaining liner margin or any clearance requirement the equipment owner identifies.

A web width alone gives the dimension of the carrier. Two rolls can have the same overall width and cut label dimensions while placing the label in different lateral positions. A centered strip might suit one line, while another has an approved offset to match its guide or print station. Confirm the position that the machine actually uses and the acceptable range with the packer and converter. The machine roll guide covers the wider equipment brief, including pitch and winding.

Avery Dennison's edge position control bulletin describes how a moving web can affect registration during converting. Use that information to ask how the converter holds and inspects the supplied position. The measured position on the finished strip still needs its own agreed reference.

Compare the flat strip and the applied sample

Retain strips from the proposed roll and, if available, an accepted roll of the same design. Identify their roll numbers and recording points. Lay each strip flat without stretching it. Measure from the same liner edge to the same cut feature in the feed direction shown on the drawing. Then record the print-to-cut relationship separately if a border or small text appears to move inside the cut outline.

Observed on the same roll Ask this owner to review
The cut label sits outside the agreed lateral range while the liner width is correct The converter reviews finished cut position and slitting. Ask for a corrected strip or revised proposal.
The cut label meets the liner dimension, but an artwork border shifts inside the cut The converter reviews print-to-cut alignment against the approved proof.
Both relationships meet the drawing, but the label moves on the bottle The packer reviews guiding, bottle location and transfer with the actual roll. Keep the roll specification open until the trial explains the shift.

For a two-lane web, give each lane its own identified reference and dimension. If a wider web will be slit, approve the measurements on the delivered lanes. A narrow trim strip or a narrow remaining liner margin can matter to the device even when the label looks correct. Ask the equipment owner to confirm the usable margin and trial at the intended setup.

Put the position in the quote

Prepare an RP Labels inquiry with the finished web drawing, actual bottle, label artwork, quantity per design and applicator model. Include the measured liner edge reference and any existing roll the packer has approved. Ask which lateral position can be quoted and how it will be confirmed on a finished specimen.
