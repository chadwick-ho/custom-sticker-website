Fanfold Bottle Labels: Confirm the Printer Feed Before Ordering

If your packer wants preprinted bottle labels in a fanfold stack for later printing, confirm that its printer accepts that input format before asking for a price. Identify the printer model, stack entry path, label pitch and fold positions. Then check the printed output against the next application step.

A fanfold stack is a continuous web folded back and forth. Rolls and separate sheets have different delivery geometry. Changing the package around the web can change how the operator loads it, where folds pass through the printer and how finished material is handled.

Start with the actual printer and output method

Zebra's ZT400-series loading instructions cover both roll and fanfold media for that equipment family. Use the manual for your actual model and configuration to establish the supported path and operating mode.

Have the equipment owner show the proposed media entry and the space available for the stack. Confirm the permitted web dimensions, media construction, sensing method and any output option that will be used. Identify whether the printer is adding data to preprinted labels or producing the entire image.

The next step matters. Hand application may use printed material directly. An automatic bottle applicator may expect a wound roll with specified orientation and tension. If printed fanfold output must be rewound, include that operation, its owner and the finished-roll check in the proposal.

Keep label repeat and fold spacing separate

Put the cut-label outline and liner edges on a flat web drawing. Mark feed direction, print side and the sensing reference. Add each fold position and the distance between folds. Ask the converter to show where its proposed fold falls relative to the label cut, gap, mark and artwork.

A perforated liner does not define a fanfold stack by itself. The perforated-liner guide concerns separation points on the supplied web. Here, the supplier and printer owner also need to agree how the continuous web is folded, loaded and fed.

Proposed delivery Drawing and sample to request
Wound roll Core, outer diameter, winding orientation, label pitch and sensor reference, using the packer's roll requirements
Fanfold stack Web dimensions, fold-to-fold distance, fold locations relative to labels, print-facing orientation and stack packing, using the printer owner's confirmed requirements

Use the proposal actually available from the converter. Compare the two formats only after the equipment and downstream application requirements are identified.

Trial a finished stack through the whole route

Ask for a sample that includes several actual folds and the proposed print, liner and label construction. Have the operator load it through the supported path and add the longest expected variable information. Inspect the print position near folds as well as between them, then complete the intended output and application steps.

Zebra's media-calibration guidance illustrates why media type and characteristics belong in a printer setup. Follow the procedure for the actual equipment. If a fold or preprint affects feeding or sensing, return the identified specimen and configuration to the equipment and converter review.

Record skipped feeds, damaged folds, print offsets or handling difficulties with the sample reference. Agree the acceptance method with the owners before treating one successful printed label as approval of the stack. If the proposed format adds a rewind or other operation, have the quote show that work and its output requirements.

Request the delivered format explicitly

Prepare an RP Labels request with the printer model, web drawing, artwork, later-print fields, quantities and downstream application method. Ask which delivery formats and trial scope can be offered against the specification. A fanfold requirement needs explicit confirmation in the proposal.

For supplement labels, keep the actual bottle and application requirements in the same brief. Use the machine-roll specification guide if a roll is selected or becomes the required final format.
