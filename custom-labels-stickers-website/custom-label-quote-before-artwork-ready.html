How to Request a Custom Label Quote Before Artwork Is Ready

You can ask for a custom label quote before the artwork is finished. Send the dimensions of the actual container, a quantity for each design, the application method and a reference for the desired look. Tell the printer which facts are confirmed and which choices you want priced as alternatives. Keep the artwork and production approval open until the file and proof are ready.

Start with the container and the order split

Measure the usable panel, including anything that interrupts it such as a shoulder, taper, seam or molded ridge. For a straight round bottle, share the outside diameter and usable straight-wall height. If the bottle is undecided, give the supplier the exact alternatives and mark the size as provisional. A volume such as 10 mL does not provide the outside diameter. The RP bottle quote planner can help build a starting brief for a straight cylindrical body.

List quantities per artwork version. If three flavors will use a shared bottle, identify each one and its quantity even while the layout is still being developed. Record whether a person applies the labels by hand or a packer runs them on a machine. For machine application, ask the packer for its roll requirements before accepting a quote tied to a different format.

Show what you want the proof to do

Send a logo you are authorized to use, approved copy if it exists, a photo of the actual bottle and a reference showing which effect you like. Mark whether the reference is for layout, finish or color. An image of a gold label can leave the production method open. Ask for a plain-print proposal and a separate foil option if those choices would materially change your budget. If a code or date will be added later, identify the area it needs and who supplies that data.

RP's FAQ invites buyers with unfinished artwork to send a logo, text, bottle photo or reference and ask whether a proof can be prepared. Its sample policy distinguishes the digital proof from a physical sample and leaves charges to the written quote. Ask the supplier to identify which design work, proof and revision scope the quotation includes.

Decide what can be priced today

If this is your situation Ask for this response
Bottle, size and quantities are fixed. Logo placement is open. Ask for a quote on the defined construction and a proof preparation line.
Material or finish is undecided. Ask for comparable alternatives with quantities and scope held constant.
Label shape or usable panel is unconfirmed. Mark the outline provisional and ask what measurement or sample would close it.
Brand copy or a barcode is still under review. Ask for budgeting and layout review. Keep production approval pending.

When a revision changes size, material, tooling or quantity, ask the printer to confirm the updated scope before releasing the order. When the layout changes within the agreed construction, review the new proof against the latest approved copy. For the final order comparison, use the delivered-scope guide to check whether all proposals cover the same supply.

Send a brief the printer can act on

Prepare an RP quote inquiry with a bottle photo or sample reference, measured dimensions, one line per design, application details and your artwork status. Ask which details the supplier can price now, what it needs before a proof, and who should approve each remaining choice. Keep the quoted assumptions with the proof revision so changes can be traced.
