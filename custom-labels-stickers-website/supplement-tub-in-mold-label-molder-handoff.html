In-Mold Labels for Supplement Tubs: Molder Handoff

In-mold labeling belongs to the container-making process. Buying in-mold labels will not turn a stock of finished empty supplement tubs into an IML project. If the tubs already exist, assess a suitable decoration applied after molding. For a new IML container order, wait for the molder's accepted label specification before committing to printed stock.

The purchase needs three connected approvals: the brand releases the content, the label converter confirms what it can supply, and the molder accepts the label for the specified container and process. A brand-approved PDF resolves only the first of those questions.

Establish whether the container has already been made

IMDA's process overview describes placing the label inside the mold before resin forms the part; the decoration becomes part of the resulting molded item. This establishes why the label and molding operation must be planned together. IMDA: In-Mold 101.

Separate the inventory you already own from the container order you are considering. Record whether each stock item is an undecorated finished tub, an already decorated tub, or printed labels intended for an identified molding job. A reorder described only as “tub labels” hides that distinction.

For existing finished tubs, a pressure-sensitive proposal needs the actual tub and application requirements. The powder-tub panel guide covers allocating copy on that container. If considering other decoration after molding, the sleeve versus pressure-sensitive guide addresses the packer's route. Neither route is a way to add an in-mold label retroactively.

Make the molder's specification the ordering reference

For a new molded-container project, ask the molder to identify the container drawing, tooling revision, resin reference and intended molding process. Request the label geometry and acceptance requirements for its actual label-handling system. A circumference measurement from a finished tub is not enough to create an IML production specification.

Ask who maintains the controlled specification and who receives revisions. The converter needs to confirm the proposed substrate, print and finish against that reference. The molder needs to accept how the label is presented and handled. The brand needs to confirm that the released graphics and content correspond to the same version.

Use a handoff record such as this before authorizing bulk printed stock:

Party Information to release Evidence to connect
Brand or content owner SKU, approved copy, artwork revision and intended quantity Approved file linked to the container and label specification
Label converter Proposed construction, cut geometry and agreed packing format Supply specification and identified trial-label batch
Molder Container, tool and process references; accepted label requirements Technical acceptance and resulting molded-sample reference
Named project owner Current versions and the next approval action One shared record of open items and release status

The final row is a coordination role, not an additional manufacturing service. Assign it to a named person so that a revised file cannot reach the converter while the molder is still reviewing an earlier version. Project-specific tolerances, handling characteristics and operating parameters must come from the responsible suppliers.

Agree how the printed labels reach the molding operation

Confirm the receiving site and contact, label orientation in each pack, quantity basis, protective packing, outer identification and the condition expected on arrival. Ask the molder how it will identify the intended job after the shipping carton is opened. The converter should confirm that it can supply and identify the labels in that agreed format.

IMDA's historical label-packaging guideline calls for agreement among the parties on packing specifications and quantities. The document was approved in 2008, reviewed in 2014, and explicitly describes itself as voluntary and non-binding. It is a useful discussion reference, not a mandatory 2026 specification or a substitute for the molder's requirements. IMDA label-packaging guideline.

Record who handles a receiving discrepancy. If orientation, identity or packing condition differs from the agreed specification, the receiving team needs a named contact and a hold decision before the labels enter production. Avoid treating a shipping receipt as technical acceptance for molding.

Approve a molded sample before the bulk commitment

Agree the trial scope and its commercial terms with the actual participants. Identify the trial labels, tooling and container material used. Review the resulting molded container for the agreed print placement, visible distortion, readable copy and coding area, alongside the container checks assigned to the molder and product-quality owner.

A loose printed label can help review graphics and construction. It cannot show the finished result after molding. Likewise, a molded sample made with another label material leaves an open difference even if its artwork looks identical. Record which proposed production inputs the sample represents and which it does not.

Release the printed-label order only when the applicable specification, receiving arrangement and molded-sample decision are connected. Keep it on hold if the brand has approved the artwork but the molder has not accepted the label, or if the trial used an unresolved substitute. A request for urgent delivery cannot supply the missing technical decision.

For a later copy change, return the changed file to the agreed approval owners. They should determine which checks must be repeated and what happens to unused labels and already decorated tubs. Keep the prior sample identifiable; do not silently relabel it as evidence for the new revision.

Keep an existing-tub label inquiry specific

If the immediate requirement is decoration for finished tubs, use the custom supplement-label page to frame a separate adhesive-label inquiry. Provide the actual tub, surface and dimensions, approved copy, quantity by SKU, application method and required delivery destination.

Prepare the tub-label brief and ask RP Labels to confirm the proposed pressure-sensitive construction, sample scope and charges. For an IML project, obtain the specification and molding acceptance from the molder and the proposed IML converter. Keep those supply responsibilities explicit in the project record.
