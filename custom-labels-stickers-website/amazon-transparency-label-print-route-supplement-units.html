Amazon Transparency Labels: Choose a Print Route for Each Unit

Two bottles of the same supplement can carry the same product artwork. Once that product uses Amazon Transparency, each sellable unit needs its own code. Before ordering labels, have the brand confirm the product and code source with Amazon. Then choose a print route the brand and packer can trace from authorized code data to one released unit.

Have the rights owner confirm the code source

For US enrollment, Amazon specifies a Brand Registry account with the rights owner role for the brand’s trademark, an active registered trademark, and a GTIN (Global Trade Item Number) for each product to enroll. Identify the exact product, including count and pack format, and record the brand contact responsible for enrollment. A packaging quote can proceed with dummy artwork while the brand confirms eligibility. Amazon US Transparency program and eligibility requirements

With Amazon-issued codes, Amazon controls code generation. The brand must be able to mark every unit it manufactures for the enrolled product, including units sold through other channels. With existing serials, the brand must qualify and connect its serials to Amazon. Amazon lists unique unit serials of 7–20 characters, external scannability, placement on the same side as the GTIN, and the ability to share all serials for the enrolled GTIN or SKU. Confirm the route with Amazon before giving a printer production data.

A lot number can repeat across bottles, a retail GTIN identifies a product, and the FNSKU used for fulfillment serves a separate inventory purpose. None of those alone establishes an accepted Transparency serial for an individual bottle. For a bottle that also carries a fulfillment label, keep its placement in the packaging proof. Supplement FNSKU print approval guide

Compare where each unit gets its code

Once the brand knows which codes it can use, ask prospective suppliers and the co-packer to name the person responsible at each handoff. Use the same bottle, run size and packing site in all three quote requests.

Print route Question for the buyer to settle before ordering
Self-print labels Who can access the authorized data, operate the printer, apply one label to each bottle and account for misprints when a run stops?
Order preprinted labels Which trusted partner is eligible for this job? Who receives the coded stock at the packer and records the unused and spoiled labels at closeout?
Integrate printing with packaging Where does the authorized variable code enter the package print job? Who matches the printed component to the enrolled SKU and holds damaged or unused components?

A co-packer may handle application under any suitable arrangement. State whether its quote covers printing, application, reconciliation or only one of those activities. Get the brand’s approval for the proposed parties and the transfer of code data before production.

Try the handoff with two dummy bottles

On samples of the sellable unit, mark one position “Demo A” and the other “Demo B.” Use them to check panel space, the visibility of existing marks and the operator’s view at application. Then model a restart: a second piece marked A appears while B has no ID. Have the operator identify both affected units, set them aside and tell the brand contact what was printed, used, spoiled and still on hand. Agree who resolves the discrepancy and authorizes release. A dummy layout can reveal a placement or handoff problem. Actual code acceptance follows the program workflow.

Keep three separate entries in the job record: the approved packaging revision, the brand’s disposition of the physical units, and Amazon’s operational review status. This lets the packer close a print job without accidentally recording a platform approval.

Schedule the review for the fulfillment route

Amazon calls for the operational performance review when labeling and shipping begin. For Fulfillment by Amazon (FBA), the brand starts it in the Transparency portal and Amazon scans arriving units. For self-fulfilled orders, the brand contacts Transparency support and supplies codes at order confirmation in Seller Central. Protection starts after the product passes the review. Assign a brand contact to record that result. Amazon’s operational performance review instructions

For a supplement packaging inquiry, send RP Labels the product format, quantity, proposed panel, brand-selected code route, application owner and a dummy layout. Ask which print components it can quote for this project. Keep live codes, account credentials and customer information out of the inquiry.
