One approval covers the preprinted design. Another must cover what changes at the packing line. A vial can carry the correct blue label, logo and product name but the wrong lot field. The art department cannot inspect a date that has not been printed yet.

For a custom peptide vial label, I would separate the permanent design from the changing data in the purchase specification. The first layer is the approved SKU identity and graphic artwork. The second is the approved field map for lot, date, serial or code data. This article is about the handoff between those layers, not an invitation to put unverified pharmaceutical claims on a research label.

Decide when each field is actually printed

A converter may preprint the colour artwork and reserve a suitable panel for later on-demand marking. Alternatively, a digital workflow may print both in one controlled pass. The right choice depends on where the authoritative lot data lives, when it becomes final, the quantity per SKU and the available inspection equipment. GS1's barcode planning guidance describes preprinting multicolour graphics while leaving space for dynamic information added inline. It does not prescribe that workflow for every vial.

The buyer should ask a less glamorous question than “Can you print variable data?”: who loads the data file, who approves its format, and who checks that the last printed label belongs to the same job as the first? If a printer can handle the artwork but the data handoff is a spreadsheet forwarded without version control, the production risk has merely moved.

Write a field map a packer can use

Identify each variable field by name, permitted characters, maximum length and source system. State whether the field is human-readable, machine-readable or both. Put the location on a production-size proof, not a zoomed PDF alone. Leave space for the worst permitted value, not the shortest example. A field that fits LOT A1 may collide with the seam when a longer real identifier arrives.

If a 2D code is involved, specify its actual symbology and data structure before artwork approval. Do not call every square pattern “a QR code.” GS1's 2D implementation guidance explains why a variable batch or date may require printing at the production line. The right quality criteria depend on the chosen symbol and scanning use case; a decorative sample code in a mockup proves nothing.

The first-middle-last approach is a practical sampling proposal, not a universal statistical standard. The buyer and printer should agree on the actual frequency, what triggers a stop, and what happens to labels printed during a rejected interval. For codes, GS1's verification guidance distinguishes symbol quality verification from simply obtaining a phone scan. A scanner reading one label once does not establish the quality of an entire run.

Use the applied vial for the final look

A code at the edge of a flat proof may curve away when wrapped on a 2 mL vial. Text can fall behind the vial's back seam. Test on the actual glass or plastic sample, under the lighting and handling that the buyer expects. Keep a complete printed strip for inspection, then compare an applied vial to the approved art and data record. The QR and batch layout guide covers the layout decision; this release check is about proving the final data made it into the right place.

When the line changes SKU, require a positive clearance step: remove leftover labels, load the new approved file and first-good sample, and record who restarted. A beautiful label left on a table can become the wrong label in the next run. That is a process question for the buyer and packer to settle, not a promise that any label supplier can control another company's line.

What belongs in the quote request

Send the container dimensions, number of SKUs, static artwork files, a sample data schema with dummy values, final print method, expected lot length, code type if used, application method and desired inspection record. State which party owns the content of the variable data. Ask whether the proposed facestock and finish accept the intended overprint method; our thermal-transfer material guide goes deeper on ribbon and coating compatibility.

I would hold the order if nobody can answer who signs off the final printed lot. An artwork proof is worth approving. It just is not the final release.
